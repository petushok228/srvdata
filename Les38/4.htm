Тема 5. Указатели в C#.
    Назад

C# поддерживает указатели в ограниченной степени. Указатель C# — это не что иное, как переменная, содержащая адрес памяти другого типа. Но в C# указатель может быть объявлен только для хранения адреса в памяти типов значений и массивов. В отличие от ссылочных типов, типы указателей не отслеживаются механизмом сборки мусора по умолчанию. По этой же причине указатели не могут указывать на ссылочный тип или даже на тип структуры, который содержит ссылочный тип. Можно сказать, что указатели могут указывать только на неуправляемые типы, которые включают в себя все основные типы данных, типы перечислений, другие типы указателей и структуры, которые содержат только неуправляемые типы.

в C# указатель может быть объявлен только для хранения адреса в памяти типов значений и массивов.

Общая форма объявления типа указателя выглядит следующим образом:

тип *variable_name;

Где * известен как оператор разыменования. Например, следующее утверждение

int *x ;

Объявляет переменную-указатель x, которая может содержать адрес типа int. Ссылочный оператор (&) можно использовать для получения адреса переменной в памяти.

int x = 100;

&x дает адрес переменной x в памяти, который мы можем присвоить переменной указателя

int *ptr = & x;.
Console.WriteLine((int)ptr) // Displays the memory address
Console.WriteLine(*ptr) // Displays the value at the memory address.

Небезопасные коды

Операторы C# могут выполняться как в безопасном, так и в небезопасном контексте. Операторы, помеченные как небезопасные с помощью ключевого слова unsafe, работают вне контроля сборщика мусора. Помните, что в C# любой код, включающий указатели, требует небезопасного контекста.

Мы можем использовать ключевое слово unsafe двумя разными способами. Его можно использовать в качестве модификатора метода, свойства, конструктора и т.д. Например

// Author: rajeshvs@msn.com
using System;
class MyClass
{
    public unsafe void Method()
    {
        int x = 10;
        int y = 20;
        int* ptr1 = &x;
        int* ptr2 = &y;
        Console.WriteLine((int)ptr1);
        Console.WriteLine((int)ptr2);
        Console.WriteLine(*ptr1);
        Console.WriteLine(*ptr2);
    }
}
class MyClient
{
    public static void Main()
    {
        MyClass mc = new MyClass();
        mc.Method();
    }
}

Ключевое слово unsafe также можно использовать для обозначения группы утверждений как небезопасных, как показано ниже.

// Author: rajeshvs@msn.com

using System;
class MyClass

            Console.WriteLine(*ptr2);
        }
    }
}

    {

Закрепление объекта

Сборщик мусора C# может перемещать объекты в памяти по своему усмотрению в процессе сборки мусора. В C# есть специальное ключевое слово fixed, указывающее сборщику мусора не перемещать объект. Это означает, что это фиксирует в памяти расположение типов значений, на которые указываются. В C# это называется закреплением.

Оператор fixed обычно реализуется путем создания таблиц, которые описывают сборщику мусора, какие объекты должны оставаться фиксированными в тех или иных областях исполняемого кода. Таким образом, до тех пор, пока процесс сборщика мусора фактически не происходит во время выполнения фиксированных операторов, это связано с очень небольшими затратами. Однако, когда процесс сборщика мусора все же происходит, исправленные объекты могут привести к фрагментации кучи. Следовательно, объекты должны быть зафиксированы только в случае крайней необходимости и только на самый короткий промежуток времени.

Указатели и конверсии

В C# типы указателей не наследуются от объекта, и преобразование между типами указателей и объектами не выполняется. Это означает, что упаковка и распаковка не поддерживаются указателями. Но C# поддерживает преобразования между различными типами указателей, типами указателей и целочисленными типами.

C# поддерживает как неявные, так и явные преобразования указателей в небезопасном контексте. К неявным преобразованиям относятся следующие

  1. От типа указателя любого типа до типа void *.
  2. От нулевого типа до любого типа указателя.

Оператор приведения (()) необходим для любых явных приведений типов. К явным приведениям типов относятся следующие виды

  1. От любого типа указателя к любому другому типу указателя.
  2. От sbyte, byte, short, ushort, int, uint, long, ulong до любого типа указателя.
  3. От любого типа указателя до типов sbyte, byte, short, ushort, int, uint, long, ulong.

Например

char c = 'R';
char *pc = &c;
void *pv = pc; // Implicit conversion
int *pi = (int *) pv; // Explicit conversion using casting operator

Арифметика указателей

В небезопасном контексте операторы ++ и - могут быть применены к переменной указателя всех типов, кроме типа void *. Таким образом, для каждого указателя типа T* неявно перегружаются следующие операторы.

T* operator ++ (T *x);
T*operator -- (T *x);

Оператор ++ прибавляет sizeof(T) к адресу, содержащемуся в переменной, а оператор - вычитает sizeof(--) из адреса, содержащегося в переменной, для переменной-указателя типа T*.

В небезопасном контексте константа может быть добавлена или вычтена из переменной указателя. Аналогично, переменная указателя может быть вычтена из другой переменной указателя. Но добавить две указательные переменные в C# невозможно.

В небезопасном контексте = =, ! Операторы =, <, >, < =, > = могут быть применены к типам значений всех типов указателей. Умножение и деление переменной указателя на константу или на другую переменную указателя в C# невозможно.

Распределение стека

В небезопасном контексте локальное объявление может включать инициализатор выделения стека, который выделяет память из стека вызовов.

Stackalloc T[E] требует, чтобы T был неуправляемым типом, а E — выражением типа int. Приведенная выше конструкция выделяет E * sizeof(T) байт из стека вызовов и создает указатель типа T* на вновь выделенный блок. Значение E отрицательное, генерируется исключение System.OverFlowException. Если памяти недостаточно для выделения, создается исключение System.StackOverflowException.

Содержимое вновь выделенной памяти не определено. Не существует способа неявно освободить память, выделенную с помощью stackalloc. Вместо этого все выделенные стеком блоки памяти автоматически отбрасываются после возврата функции.

Указатели и массивы

В C# доступ к элементам массива можно получить с помощью нотации указателей.

// Author: rajeshvs@msn.com
using System;
class MyClass
{
    public unsafe void Method()
    {
        int[] iArray = new int[10];
        for (int count = 0; count < 10; count++)
        {
            iArray[count] = count * count;
        }
        fixed (int* ptr = iArray)
            Display(ptr);
        //Console.WriteLine(*(ptr+2));
        //Console.WriteLine((int)ptr);
    }
    public unsafe void Display(int* pt)
    {
        for (int i = 0; i < 14; i++)
        {
            Console.WriteLine(*(pt + i));
        }
    }
}
class MyClient
{
    public static void Main()
    {
        MyClass mc = new MyClass();
        mc.Method();
    }
}

Указатели и структуры

Структуры в C# являются типами значений. Указатели можно использовать со структурами, если они содержат только типы значений в качестве своих членов. Например

// Author: rajeshvs@msn.com
using System;
struct MyStruct
{
    public int x;
    public int y;
    public void SetXY(int i, int j)
    {
        x = i;
        y = j;
    }
    public void ShowXY()
    {
        Console.WriteLine(x);
        Console.WriteLine(y);
    }
}
class MyClient
{
    public unsafe static void Main()
    {
        MyStruct ms = new MyStruct();
        MyStruct* ms1 = &ms;
        ms1->SetXY(10, 20);
        ms1->ShowXY();
    }
}
