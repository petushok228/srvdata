Где писать код (form.cs или program.cs)?
    Назад
А вот в Windows Form возникают некоторые проблемы.
Создадим пустое приложение и поместим на него кнопку. Сделаем двойной клик по кнопке. Visual Studio откроет файл Form1.cs. Тем не менее, его нет в инспекторе объектов. Я знаю, что можно сделать Form.cs - > Перейти к коду. Но так или иначе странно, что файл кода и файл формы представлены в инспекторе как один объект. Говоря проще - где в инспекторе Form1.cs (во вложенном меню тоже не нашел)? Инспектор должен показывать мое текущее местоположение. В то же время другой cs файл - Program.cs представлен отдельно.

Собственно отсюда вытекает основной вопрос - где писать код? В form.cs или program.cs?

namespace WindowsFormsApp2
{
    static class Program
    {
        /// <summary>
        /// Главная точка входа для приложения.
        /// </summary>
        [STAThread]
        static void Main()
        {
            Application.EnableVisualStyles();
            Application.SetCompatibleTextRenderingDefault(false);
            Application.Run(new Form1());
        }
    }
}
Main() как бы говорит - пиши код здесь. Более того Application.Run(new Form1) показывает, что отсюда идет создание экземпляра Form1.
