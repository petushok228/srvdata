Перегрузка операторов для пользовательских типов

Когда мы используем оператор для пользовательских объектов, Python не знает, как с ним работать. Чтобы операторы работали с пользовательскими классами, Python предоставляет специальные методы (также называемые магическими методами). 

+ оператор -> вызывает __add__(self, other)
- оператор -> вызывает __sub__(self, other)
== оператор -> вызывает __eq__(self, other)

Итак, когда мы пишем obj1 + obj2, Python внутренне вызывает:

obj1.__add__(obj2)

Если этот метод определён в классе, то перегрузка операторов работает.

Пример 1: В этом коде показано, как перегрузить оператор + для целых чисел и строк внутри пользовательского класса. 

class A:
    def __init__(self, a):
        self.a = a
​
    # define behavior of +
    def __add__(self, o):
        return self.a + o.a 
​
ob1 = A(1)
ob2 = A(2)
ob3 = A("Geeks")
ob4 = A("For")
​
print(ob1 + ob2)   # integer addition
print(ob3 + ob4)   # string concatenation
​
# actual working (internally)
print(A.__add__(ob1, ob2))
print(ob1.__add__(ob2))

Выходной сигнал
3
GeeksFor
3
3
Объяснение:

ob1 + ob2 автоматически вызывает ob1.__add__(ob2).

Python преобразует это в A.__add__(ob1, ob2)

Первый операнд (ob1) становится self, а второй операнд (ob2) становится other.

Пример 2: В этом коде показано, как перегрузить оператор + для пользовательского класса Complex, чтобы он добавлял действительную и мнимую части по отдельности.

class Complex:
    def __init__(self, a, b):
        self.a = a
        self.b = b
​
    def __add__(self, other):
        return self.a + other.a, self.b + other.b
​
Ob1 = Complex(1, 2)
Ob2 = Complex(2, 3)
Ob3 = Ob1 + Ob2
print(Ob3)

Выходной сигнал
(3, 5)

Пояснение: Здесь Ob1 + Ob2 складывает действительные части (1 + 2) и мнимые части (2 + 3) по отдельности.

Перегрузка операторов сравнения

Такие операторы, как >, < и ==, также могут быть перегружены.

Пример 1: В этом коде показано, как перегрузить оператор > для сравнения двух объектов на основе их сохранённых значений.

class A:
    def __init__(self, a):
        self.a = a
    
    def __gt__(self, other):
        return self.a > other.a
​
ob1 = A(2)
ob2 = A(3)
if ob1 > ob2:
    print("ob1 is greater than ob2")
else:
    print("ob2 is greater than ob1")

Выходной сигнал
ob2 is greater than ob1

Пример 2: В этом коде показано, как перегрузить операторы < и == для пользовательских сравнений. 

class A:
    def __init__(self, a):
        self.a = a
    
    def __lt__(self, other):
        return "ob1 is less than ob2" if self.a < other.a else "ob2 is less than ob1"
    
    def __eq__(self, other):
        return "Both are equal" if self.a == other.a else "Not equal"
​
ob1 = A(2)
ob2 = A(3)
print(ob1 < ob2)
​
ob3 = A(4)
ob4 = A(4)
print(ob3 == ob4)

Выходной сигнал
ob1 is less than ob2
Both are equal

Неассоциативные операторы

Не все операторы можно объединять в цепочки. Некоторые из них не являются ассоциативными. Например, = и += нельзя объединить в одном выражении. 

a = 5
b = 10
c = 15
​
# Invalid: mixing assignment (=) and +=
# a = b = (a < b) += (b < c)

Пояснение: В Python = (присваивание) и += (расширенное присваивание) нельзя использовать в одном выражении, так как они неассоциативны.

Перегрузка логических операторов

Мы также можем перегружать логические операторы с помощью магических методов: 

и: __and__(self, other)
или: __or__(self, other)
не: __not__(self)

Пример: В этом коде показано, как перегрузить оператор & так, чтобы он работал как логическое И для пользовательских объектов. 

class MyClass:
    def __init__(self, value):
        self.value = value
​
    def __and__(self, other):
        return MyClass(self.value and other.value)
​
a = MyClass(True)
b = MyClass(False)
c = a & b  
print(c.value)

Выходной сигнал

False

Пояснение: Здесь мы переопределили & так, чтобы он работал как логическое И для пользовательских объектов.

Особые (волшебные) методы перегрузки операторов

В Python для каждого оператора предусмотрены специальные магические методы.

Бинарные операторы
Оператор	Волшебный Метод
+	__add__(self, other)
-	__sub__(self, other)
*	__mul__(self, other)
/	__truediv__(self, other)
//	__floordiv__(self, other)
%	__mod__(self, other)
**	__pow__(self, другое число)
Операторы сравнения
Оператор	Волшебный Метод
<	__lt__(self, other)
>	__gt__(self, other)
<=	__le__(self, other)
>=	__ge__(self, other)
==	__eq__(self, other)
!=	__ne__(self, other)
Операторы присваивания
Оператор	Волшебный Метод
-=	__isub__(self, other)
+=	__iadd__(self, other)
*=	__imul__(self, other)
/=	__itruediv__(self, other)
//=	__ifloordiv__(self, other)
%=	__imod__(self, other)
**=	__ipow__(self, other)
Унарные операторы
Оператор	Волшебный Метод
-	__нег__(самость)
+	__pos__(самовывоз)
~	__инвертировать__(self)

Преимущества

  • Перегрузка операторов в пользовательских классах даёт ряд преимуществ:

  • Улучшена читаемость: код выглядит естественно (например, ob1 + ob2 вместо ob1.add(ob2)).

  • Согласованность со встроенными типами: пользовательские объекты ведут себя как целые числа, строки и т. д.

  • Лаконичность: меньше шаблонного кода.

  • Пользовательское поведение: расширение операторов для пользовательских классов (например, векторов, матриц).

  • Расширенная функциональность: позволяет операторам эффективно работать с новыми типами данных.
