Урок 62. Назначение интерфейсов. Особенности применения интерфейсов в C#.
    Оглавление

 
Интерфейс описывает функциональные возможности без конкретной реализации. Иными словами интерфейс определяет спецификацию но не реализацию.
Интерфейс в языке программирования C# — это ссылочный тип, который определяет некоторый функционал — набор методов и свойств без реализации. Затем этот функционал реализуют классы и структуры, которые применяют интерфейс.
Интерфейс - это структура кода, которая подобна абстрактному классу, не имеющему конкретных членов.
Особенности интерфейсов:
  * Могут содержать методы, свойства, индексаторы и события.
  * Не могут содержать нестатические переменные.
С версии C# 8.0 интерфейсы поддерживают реализацию методов и свойств по умолчанию.
Объявление
Для объявления интерфейса используется ключевое слово interface. Как правило, названия интерфейсов в C# начинаются с заглавной буквы I, например, IComparable, IEnumerable (венгерская нотация).
Упрощённая форма объявления интерфейса:
interface имя { возвращаемый_тип имя_метода_1 (список_параметров);
возвращаемый_тип имя_метода_2 (список_параметров); // ...
возвращаемый_тип имя_метода_N (список_параметров); }.

Важно: в объявлении методов интерфейса используются только их возвращаемый тип и сигнатура, они, по существу, являются абстрактными методами.

Реализация
Интерфейс может быть реализован в одном или нескольких классах. Общая форма реализации интерфейса в классе:
class имя_класса : имя_интерфейса { // тело класса }.
Некоторые особенности реализации:
Если интерфейс реализуется в классе, это должно быть сделано полностью, реализовать интерфейс выборочно и только по частям нельзя.
В классе допускается реализовывать несколько интерфейсов — в этом случае все реализуемые интерфейсы указываются списком через запятую.
Методы, реализующие интерфейс, должны быть объявлены как public — в самом интерфейсе эти методы неявно подразумеваются как открытые, поэтому их реализация также должна быть открытой.
