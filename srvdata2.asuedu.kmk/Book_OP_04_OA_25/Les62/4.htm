Самостоятельная работа по теме реализация интерфейса.
    Назад

Реализовать интерфейс для определения площади и периметра фигуры:

  • метод определения площади треугольника;
  • периметр треугольника;
  • метод определения площади прямоугольника;
  • периметр  прямоугольника;
  • метод определения площади круга;
  • метод определения длины окружности;
  • метод определения объема шара;
  • метод ввода с клавиатуры переменных для вычислений;
  • метод формирование вывода информации по расчету площадей фигур.

Реализовать 2 интерфейса: первый - интерфейс FigureArea определения площади и второй определение периметра FigurePerim

 

В результате получим следующую диаграмму:

Реализовать отдельно три класса по расчету фигур. В каждом классе реализовать метод ввода с клавиатуры переменных для вычислений. Отчет о выполнении работы разместить на ПК преподавателя.
