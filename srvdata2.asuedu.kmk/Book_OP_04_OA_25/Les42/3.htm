Тема 3. Разница между Array и ArrayList.
    Назад

В следующей таблице перечислены различия между Array и ArrayList в C#.

Массив ArrayList (Список массивов)
Должен включать пространство имен System для использования массива. Необходимо включить пространство имен System.Collections для использования ArraList.
Объявление массива и инициализация:
int[] arr = new int[5]
int[] arr = new int[5]{1, 2, 3, 4, 5};
int[] arr = {1, 2, 3, 4, 5};		 Объявление и инициализация ArrayList:
ArrayList arList = new ArrayList();
arList.Add(1);
arList.Add("Two");
arList.Add(false);
Array хранит фиксированное количество элементов. Размер массива должен быть указан во время инициализации. ArrayList растет автоматически, и вам не нужно указывать размер.
Array строго типизирован. Это означает, что в массиве могут храниться только определенные типы элементов\элементов. ArrayList может хранить любые типы элементов\элементов.
Нет необходимости приводить элементы массива во время извлечения, так как он строго типизирован и хранит только определенный тип элементов. Элементы ArrayList должны быть приведены к соответствующему типу данных во время получения. Итак, происходит бокс и распаковка.
Работает быстрее, чем ArrayList, так как строго типизирован. Выполняет замедления из-за распаковки и распаковки.
Используйте статический вспомогательный класс Array для выполнения различных задач на массиве. Сам ArrayList включает в себя различные служебные методы для различных задач.
