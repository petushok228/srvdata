Практическая работа 12. Объединение разнородных элементов (Запись). 

Формируемые общие и профессиональные компетенции ОК 01, ОК 02, ОК 03, ОК 04, ОК 05, ОК 06, ОК 07, ОК 08, ОК 09, ПК 1.2, ПК 1.4, ПК 1.5.  

Формируемые личностные результаты: ЛР13, ЛР17.  

Краткая аннотация.

Подчиненные формы особенно удобны для вывода данных из таблиц или запросов, связанных с отношением «один-ко-многим». Например, можно создать форму с подчиненной формой для вывода данных из таблицы «Типы» и из таблицы «Объекты». Данные в таблице «Типы» находятся на стороне «один» отношения. Данные в таблице «Объекты» находятся на стороне «многие» отношения — каждый тип может иметь несколько объектов.
