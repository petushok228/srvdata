Тема 2. Что такое декоратор отправки? .
    Назад

В Python декоратор @dispatch используется для перегрузки функций с разными сигнатурами. Это распространенный шаблон в объектно-ориентированном программировании, когда несколько методов могут иметь одно и то же имя, но разные параметры или типы аргументов. Декоратор @dispatch позволяет вам написать одну функцию с несколькими реализациями, которые будут выбраны во время выполнения на основе аргументов, переданных функции.

В Python декораторы — мощная и широко используемая функция языка. Они позволяют вам изменять или улучшать поведение функций, классов или модулей без изменения их исходного кода. Одним из таких декораторов является Dispatch Decorator, который обеспечивает динамическую диспетчеризацию вызовов функций в зависимости от типа переданных им аргументов. 

Что такое декоратор отправки?

Dispatch Decorator — это декоратор, который позволяет вам определить функцию, которую можно вызывать с различными типами аргументов, а затем динамически отправляет вызов соответствующей реализации в зависимости от типа переданных аргументов. Диспетчеризация осуществляется во время выполнения в зависимости от типа аргументов и позволяет определить несколько реализаций одной и той же функции для разных типов аргументов. 

Пример

Чтобы реализовать декоратор Dispatch в Python, вы можете использовать модуль functools, который предоставляет декоратор под названием Singledispatch.

Декоратор singledispatch можно использовать для создания универсальной функции, которая может управлять своим поведением в зависимости от типа первого переданного ей аргумента. 

from functools import singledispatch
@singledispatch
def add(x, y):
   raise NotImplementedError("Unsupported type")
@add.register
def _(x: int, y: int) -> int:
   return x + y
@add.register
def _(x: str, y: str) -> str:
   return x + y 

В приведенном выше примере мы определили общую функцию add, которая принимает два аргумента x и y. Затем мы определили две реализации функции add для типов int и str. Мы использовали метод Register для регистрации каждой реализации функции с помощью функции add . Когда мы вызываем функцию add с двумя аргументами типа int, она вызывает реализацию, которая принимает два целых числа и возвращает целое число. Аналогично, когда мы вызываем функцию add с двумя аргументами типа str, она вызывает реализацию, которая принимает две строки и возвращает строку.

Пример

Вот пример того, как использовать функцию добавления: 

>>> add(1, 2)
3
>>> add("Hello, ", "world!")
"Hello, world!" 

Как работает декоратор @dispatch? 

Декоратор @dispatch является частью библиотеки Multipledispatch и используется для создания нескольких реализаций одной функции. Декоратор определяет механизм диспетчеризации, который выбирает используемую реализацию на основе количества и типов аргументов, передаваемых функции. 

Пример 

from multipledispatch import dispatch
@dispatch(int)
def square(x):
   return x * x
@dispatch(int, int)
def square(x, y):
   return x * y 

В приведенном выше примере мы определили две реализации функции Square(): одна принимает один целочисленный аргумент и возвращает его квадрат, а другая принимает два целочисленных аргумента и возвращает их произведение. Декоратор @dispatch позволяет нам определить эти две реализации, используя одно и то же имя функции.

Когда мы вызываем функцию Square() с одним аргументом, будет вызвана первая реализация —

square(2) # returns 4

Когда мы вызываем функцию Square() с двумя аргументами, будет вызвана вторая реализация

— square(2, 3) # returns 6

Декоратор @dispatch позволяет нам создавать более краткий и читаемый код, объединяя несколько функций со схожим поведением в одну функцию. 

Расширенное использование декоратора @dispatch

Декоратор @dispatch также поддерживает более сложные шаблоны использования, такие как продвижение типов и иерархию типов. Например, мы можем определить реализацию функции Square(), которая принимает аргумент с плавающей запятой, и механизм диспетчеризации автоматически преобразует число с плавающей запятой в целое число перед вызовом соответствующей реализации — 

@dispatch(float)
def square(x):
   return int(x) * int(x)

square(2.5)  # returns 4 

Мы также можем определить реализацию функции Square(), которая принимает подкласс целого числа, и она будет автоматически отправлена в целочисленную реализацию — 

class MyInt(int):
   pass
@dispatch(MyInt)
def square(x):
   return x * x
square(MyInt(2))  # returns 4
