Комплект средств разработки на C#?

Набор средств разработки C# занимает некоторые знакомые понятия из Visual Studio, чтобы обеспечить более продуктивную и надежную работу C# в VS Code. Этот подход обеспечивает отличный интерфейс при быстром редактировании файла C#, обучении C# или отладке серверного API. Набор средств разработки на C# состоит из набора расширений VS Code, которые совместно работают для обеспечения полнофункциональных возможностей редактирования C#, разработки, управления решениями и интегрированного тестирования. Как показано на следующем рисунке, набор средств разработки на C# состоит из следующих элементов:

  • Расширение C#, которое обеспечивает поддержку базовых языковых служб и продолжает поддерживаться независимо от этих усилий.

  • Расширение комплекта разработки на C#, которое строится на основе Visual Studio для управления решениями, шаблонов и отладки тестов.

  • Расширение IntelliCode для комплекта разработки на C# (необязательно), которое обеспечивает разработку на основе искусственного интеллекта в редактор.
