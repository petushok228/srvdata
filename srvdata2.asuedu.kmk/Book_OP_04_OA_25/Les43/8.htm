Преобразование строки в словарь на C#.
    Назад

При работе с данными в C# часто встречаются сценарии, где необходимо преобразовать строки в словари. Преобразования строк в словарь особенно полезны, когда вы получаете данные в сериализованном формате, таком как JSON или пары ключ-значение, и вам нужно манипулировать данными или обращаться к ним как к структуре словаря. В этой записи блога мы рассмотрим несколько методов преобразования строк в словари на C#, предоставив подробные объяснения и примеры для каждого подхода.

Способ 1: Использование класса JavaScriptSerializer

Первый метод, который мы рассмотрим, — это использование класса JavaScriptSerializer, доступного в пространстве имен. Этот класс предоставляет функциональные возможности для сериализации и десериализации данных JSON, включая преобразование строки JSON в представление словаря. Мы можем использовать этот класс следующим образом:System.Web.Script.Serialization

using System.Web.Script.Serialization;
t
// JSON string to be converted
string jsonString = "{\"key1\": \"value1\", \"key2\": \"value2\"}";

// Create an instance of JavaScriptSerializer
JavaScriptSerializer serializer = new JavaScriptSerializer();

// Convert the JSON string to a dictionary
Dictionary dictionary = serializer.Deserialize>(jsonString);

// Output the dictionary
foreach (KeyValuePair entry in dictionary)
{
    Console.WriteLine("Key: " + entry.Key + ", Value: " + entry.Value);
}

Способ 2: Использование класса JsonConvert из Newtonsoft.Json

Второй способ предполагает использование популярной библиотеки Newtonsoft.Json, которая предоставляет мощную функциональность, связанную с JSON, в C#. Класс в этой библиотеке позволяет легко преобразовывать строку JSON в словарь. Вот пример того, как это сделать:JsonConvert

using Newtonsoft.Json;
using System.Collections.Generic;

// JSON string to be converted
string jsonString = "{\"key1\": \"value1\", \"key2\": \"value2\"}";

// Convert the JSON string to a dictionary
Dictionary dictionary = JsonConvert.DeserializeObject>(jsonString);

// Output the dictionary
foreach (KeyValuePair entry in dictionary)
{
    Console.WriteLine("Key: " + entry.Key + ", Value: " + entry.Value);
}

Способ 3: Пользовательский парсинг

В некоторых случаях вы можете столкнуться со строковыми форматами, которые не являются строго JSON, но имеют аналогичную структуру. В таких сценариях можно реализовать пользовательскую логику синтаксического анализа для преобразования строки в словарь. Этот метод включает в себя ручное разделение строки и извлечение пар ключ-значение. Конкретная реализация будет зависеть от структуры вашей строки и любых специальных правил форматирования. Вот упрощенный пример, иллюстрирующий эту концепцию:

string inputString = "key1=value1;key2=value2";

// Split the string based on the delimiter
string[] keyValuePairs = inputString.Split(';');

// Create a new dictionary
Dictionary dictionary = new Dictionary();

// Parse each key-value pair and add it to the dictionary
foreach (string pair in keyValuePairs)
{
    string[] parts = pair.Split('=');
    if (parts.Length == 2)
    {
        string key = parts[0];
        string value = parts[1];
        dictionary[key] = value;
    }
}

// Output the dictionary
foreach (KeyValuePair entry in dictionary)
{
    Console.WriteLine("Key: " + entry.Key + ", Value: " + entry.Value);
}
