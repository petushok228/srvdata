Тема 10. Синтаксис C#
    Назад

Синтаксис языка программирования C# — это набор правил, которые определяют, как правильно писать код, чтобы компьютер мог его понять и выполнить. 
Основные элементы синтаксиса
Давайте разберём ключевые компоненты, из которых строится код на C#:
Комментарии. Это текстовые заметки, которые игнорируются компилятором. В C# есть два типа:

  • Однострочные — начинаются с // и продолжаются до конца строки.

  • Многострочные — заключаются между /* и */.

Ключевые слова. Это зарезервированные слова, которые имеют специальное значение для компилятора. Их нельзя использовать в качестве имён переменных, функций или других идентификаторов.

Примеры: class, public, static, void, int, if, return. 

 Идентификаторы. Это имена, которые программист даёт своим переменным, функциям, классам и другим элементам программы. Правила именования: они должны начинаться с буквы или знака подчёркивания, а после первого символа могут использоваться буквы, цифры или знаки подчёркивания. Прописные и строчные буквы в идентификаторах различаются. 

Типы данных. C# — строго типизированный язык. При объявлении переменной указывается её тип (например, int для целых чисел, string для строк, double для чисел с плавающей точкой). 


Операторы и выражения. Операторы выполняют действия над данными (например, арифметические операции +, -, сравнение ==, логические операции &&, ||). Выражения комбинируют операнды и операторы для получения значения. 

Управляющие конструкции. С их помощью меняется поток выполнения программы. К ним относятся условные операторы (if, switch), циклы (for, while, foreach), а также операторы перехода (break, continue, return). 

Блоки кода. Для группировки инструкций используются фигурные скобки {}. Например, тело метода или составной оператор внутри условия.


Методы и их объявление. Метод в C# — это блок кода, решающий какую-то задачу. Его синтаксис включает возвращаемый тип, имя, список параметров в скобках и тело метода.
Пространства имён и типы. Всё в C# организуется в пространства имён (namespaces). Для доступа к типам из другого пространства имён используется их полное имя.
Пример простой программы
Вот как выглядит минимальный пример программы на C#:
using System;

namespace HelloWorld
{
class Program
{
static void Main()
{
Console.WriteLine("Привет, мир!");
}
}
}
Разберём его:
using System; — подключение пространства имён System, которое содержит базовые классы, например Console для ввода-вывода.
namespace HelloWorld — указание области видимости.
class Program — объявление класса.
static void Main() — метод Main, который является точкой входа в программу. Ключевое слово static означает, что метод принадлежит классу, а не экземпляру. voidуказывает, что метод не возвращает значение.
Console.WriteLine("Привет, мир!"); — вывод текста на консоль.
{} — ограничители тела метода Main.
Важные нюансы
Чувствительность к регистру. Идентификаторы и ключевые слова в C# чувствительны к регистру (Age и age — разные вещи).
Точка с запятой в конце инструкций. В C# каждая инструкция (например, объявление переменной, вызов метода) должна заканчиваться точкой с запятой ;.
Регистр букв в идентификаторах имеет значение. MyVariable и myVariable — это разные имена.
