1. Создать каталог для выполнения практических и самостоятельных работ на диске D: общий каталог группы: !22-IS-12_Algo

2. Создать каталоги для проектов отдельно для каждого языка программирования.  Три папки для решений: BakulinCharp, BakulinPac и BakulinPyt (ваша фамилия и язык программирования)

3. Создать первый проект для каждого языка. В первой программе выполнить вывод на экран строки: Это работа Иванова Д. Это первый проект на языке программирования C#.

Ход выполнения работы:

Создание программы на Pascal
1. Запускаем среду разработки.
2. Создаем по шаблону консольное приложение
3. Убираем ряд панелей: инспектор объектов, Визуальные компаненты
4. Создаем каталог для самостоятельной работы Sr3 через проводник

Создание программы на C#
1. Запускаем среду разработки.
2. Выбираем раздел Создание проекта
3. В диалоговом окне выбираем язык программирования C#,
выбираем ОС Windows, выбираем шаблон приложения Консоль, нажимаем Далее
4. Настраиваем проект:
имя проекта Sr3 -наименование урока
расположение ваша папка для проектов по программированию
имя решения BakulinCharp

Создание программы на Python

4. Настраиваем проект:
