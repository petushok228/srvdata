Практическая работа 7. Работа со строками. Задачи.
    Назад

1. Составить программу, записывающую слово X в обратном порядке.

2.        Записать программу, удваивающую каждую букву слова Х.

3.        Выделить в слове Х каждую букву "о" с помощью тире слева и справа.

4.        Заменить в слове Х все буквы "а" на сочетание "ку"

5.         В слове Х перед каждой буквой "к" вставить букву "н".

6.        Заменить в слове Х все буквы "а" на сочетание "l1"

7.        Написать программу для вычеркивания всех букв "о", стоящих в слове X на четных местах.

8.        Составить программу для вычеркивания в слове X всех букв, стоящих после буквы "а".

9.        Записать программу, которая из исходной строки  (Лучший город Калининград) составляет новую, в которую переписываются только  буквы ш, К,и, р, г   из исходной

10.     Написать программу для вычеркивания из слова X всех букв "р", перед которыми стоит буква "а".

11.     Записать программу, которая из исходной строки составляет новую, в которую переписываются только гласные буквы исходной

(В русском языке 10 гласных букв: а, у, о, ы, и, э, я, ю, ё, е.)

12.     Дана последовательность, содержащая от 2 до 30 слов; между соседними словами - не менее одного пробела.  Удалить из слова первую букву

13.     Записать программу, которая из исходной строки составляет новую, в которую переписываются только согласные буквы исходной  (В русском языке 21 согласная буква: б, в, г, д, ж, з, й, к, л, м, н, п, р, с, т, ф, х, ц, ч, ш, щ. )

14.      Дана последовательность, содержащая от 2 до 30 слов; между соседними словами - не менее одного пробела. :  удалить из каждого слова последнюю букву;

15.     Заменить в слове Х все буквы "а" на сочетание "ok", а все буквы “d” на «W»

16.     Написать программу для подсчета числа букв "о", стоящих в слове X на четных местах.

17.     Написать программу для подсчета суммы мест, на которых в слове X стоит буква "б".

18.     Написать программу для подсчета в слове X всех сочетаний "нн". Считать, что в последовательности "ннн" "нн" встречается 1 раз.

19.     Написать программу для вычеркивания из слова X всех букв "о", после которых стоит буква "а".

20.     Записать программу, которая из исходной строки составляет новую, в которую переписываются все гласные буквы исходной, а согласные удваиваются

21.     Записать программу для подсчета количества слов в заданном тексте.

22.     Записать программу, которая из исходной строки составляет новую, в которую переписываются только гласные буквы исходной

23.     Написать программу для подсчета количества мест, на которых в слове X стоит буква "n".

24.     Записать программу, которая из исходной строки составляет новую, в которую переписываются только буквы Q,W,E,R,T,Y исходной строки

25.     Выяснить, является ли данное слово "перевертышем",

26.     Записать программу, выясняющую, есть ли в слове X буква "a", стоящая на нечетном месте после буквы "к".

27.     Составить программу, проверяющую, все ли буквы слова X одинаковы.

28.     Написать программу для подсчета числа букв "о", стоящих в слове X на нечетных местах.

29.     Записать программу, которая из исходной строки составляет новую, в которую переписываются все согласные буквы исходной, а гласные удваиваются

30.     Записать программу, выясняющую, можно ли из букв слова X составить слово Y.
