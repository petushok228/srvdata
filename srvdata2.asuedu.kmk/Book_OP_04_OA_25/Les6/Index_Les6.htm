Урок 6. Константы. Переменные. Структурированные типы данных.
    Оглавление

 

Переменная характеризуется:

  • Именем («обозначением ячейки памяти»)
  • Значением (данными, содержащимися в переменной в конкретный момент времени)
  • Типом (определяющим:
    • какие значения может принимать переменная;
    • какие операции можно производить с этими значениями;
    • как данные представлены в памяти компьютера)
  • Константа  — это число, символ или символьная строка, которую можно использовать в программе в качестве значения. Константы служат для представления значений с плавающей запятой, целых чисел, перечислений или символов, изменение которых невозможно.
    Существуют следующие стили именования переменных и функций:
  • Верблюжья нотация (camel case). Первое слово пишется со строчной буквы, следующие — с заглавной, разделителей между составными частями нет.
  • Нотация Паскаля (Pascal case). Тот же camelCase, но все слова, даже первое, начинаются с заглавной буквы.
  • Змеиная нотация (snake case). Слова разделяются символами подчёркивания. Шашлычная нотация (kebab case). В этой нотации слова разделяют символом дефиса.
  • Плоская нотация (flat case). Чтобы получить наименование в этом стиле, нужно просто записать слова рядом без пробелов, все буквы каждого слова должны быть строчными.
