Урок 10. Пр. 2. Составление программ разветвляющейся структуры.
    Оглавление

 
Эти задачи  позволят начинающим освоить составление программ разветвляющейся структуры с использованием языка C#, Pascal и Python.
Они позволяют проверить такие навыки программирования, как ввод/вывод данных, составление простейших программ вычислений по составлению разветвляющейся структуры программ и множественного выбора.

Задача 5.0 Создать калькулятор (В классе на C#)
  1. Задачи 1. Условный оператор. (варианты заданий)
  2. Задачи 2. Целочисленная арифметика и условный оператор.  (варианты заданий)
  3. Задачи 3. Целочисленная арифметика. Нахождение целого числа по информации о его цифрах.   (варианты заданий)
  4. Задачи 4. Целочисленная арифметика. Задачи повышенной сложности.   (варианты заданий)
  5. Самостоятельная работа 2. Множественный выбор Switch.
  6. Пример использования оператора switch C#
  7. Пример использования оператора Case Pascal
  8. Практическая работа 2.1.  Оператор множественного выбора (switch)
  9. Практическая работа 2.2. Составление программ разветвляющейся структуры.
  10. Ветвления (условные операторы). Примеры решение задач.
