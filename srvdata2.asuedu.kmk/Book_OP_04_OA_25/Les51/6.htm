Задание 2  Создать класс по обработке сведений о приеме товара на склад.  

Создать класс, конструктов, поля и методы.

В классе использовать следующие методы:

  1. Прием товара с сохранением в файле
  2. Формирование ведомости о поступлении товара (квитанция о принятом товаре) Использовать поля: № квитанции, дата приема, наименование товара, количество, цена за единицу(вещественное число)

  1. В одну квитанцию включить не менее трех наименований
  2. Оформить прием товара по 3 квитанциям за день ( определить стоимость по каждой позиции и общую стоимость принятого товара по квитанции)
  3. Оформить прием товара за три дня
  4. Сформировать отчет о приеме товара по одной квитанции
  5. Сформировать отчет о приеме за один день
  6. Сформировать отчет о приеме за три дня
