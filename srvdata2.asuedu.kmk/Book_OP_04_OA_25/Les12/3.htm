Тема 3. Определение числа разряда  из двухзначного.
    Назад

Вот пример кода на Pascal, который находит и выводит каждую цифру трёхзначного числа:

program ExtractDigits;

var
  n,
  hundreds,    // переменная для цифры сотен
  tens,        // переменная для цифры десятков
  units:       // переменная для цифры единиц

begin
  writeln('Введите трёхзначное число:');
  readln(n);

  // Находим цифры с помощью операций div и mod
  hundreds := n div 100;        // Целочисленное деление на 100 даёт цифру сотен
  tens := (n mod 100) div 10;     // Остаток от деления на 100, затем целочисленное деление на 10 — цифра десятков
  units := n mod 10;             // Остаток от деления на 10 — цифра единиц

  // Выводим результат
  writeln('Цифры числа: сотни = ', hundreds, ', десятки = ', tens, ', единицы = ', units);
end.

Как это работает:

  • Цифра сотен: n div 100 — целочисленное деление на 100 «отсекает» последние две цифры, оставляя первую.

  • Цифра десятков: (n mod 100) div 10 — сначала отбрасываем сотни операцией mod 100, затем делим на 10, чтобы осталась средняя цифра.

  • Цифра единиц: n mod 10 — остаток от деления на 10 даёт последнюю цифру.

Пример работы: Если ввести число 238, программа выведет: Цифры числа: сотни = 2, десятки = 3, единицы = 8

Задача 15. Найти двузначное число, равное утроенному произведению его цифр. (есть пример)
program Project1;

 var
    number, tens, units, product: Integer;

begin
    // Перебор всех двузначных чисел от 10 до 99
    for number := 10 to 99 do
    begin
        // Разделение числа на десятки и единицы
        tens := number div 10; //десятки
        units := number mod 10;  //единицы

        // Вычисление произведения цифр
        product := tens * units;

        // Проверка условия: число равно утроенному произведению своих цифр
        if number = 3 * product then
        begin
            writeln('Число, удовлетворяющее условию: ', number);
        end;
    end;
    readln;
end.
