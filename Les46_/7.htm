C# String.Split

В C# мы можем использовать String . Split(), который разбивает строку на массив строк, поэтому в этой статье я упомянул несколько возможных способов использования метода String.Split() и как мы можем разбить строку на массив на примере консольного приложения.

.Split() Разделителями методов могут быть символы или массивы символов или массив строк. Существует около 10 перегрузок для метода String.Split(). Обычно используются:

  • Split(Char[])Разбивает строку на подстроки на основе заданных разделяющих символов.
  • Split(Char, StringSplitOptions): Разбивает строку на подстроки на основе указанного разделяющего символа и, опций
  • Split(Char[], Int32): Первый аргумент указывает, разделяющий символ, а второй указывает максимальное количество подстрок.
  • Split(String, StringSplitOptions): Разбивает строку на подстроки, которые основаны на предоставленном разделителе строк.
  • Split(Char[], StringSplitOptions): Разбивает строку на подстроки на основе указанных разделяющих символов и параметров.
  • Split(String[], StringSplitOptions): Разбивает строку на подстроки на основе строк в массиве.

Разбиение строки на массив с помощью запятой

Давайте рассмотрим пример консольного приложения, в котором мы будем разбивать строку на массив с помощью запятой в качестве разделителя в C#

using System;

namespace StringSplitArray
{
    public class Program
    {
        static void Main(string[] args)
        {
            var names = "Vikram,Vikas,Vinod,Hitesh,Prem";
            //split names string into array
            string[] namesList = names.Split(",");

            //loop and print
            foreach (string name in namesList)
            {
                Console.WriteLine(name);
            }

        }
    }
}

C# разделять строки и опускать пустые записи

Разделение строк может привести к появлению пустых записей. Чтобы этого избежать, мы можем Воспользуйтесь опцией.StringSplitOptions.RemoveEmptyEntries

Program.cs
var text = "There  is an old  hawk in the sky";

var words = text.Split(' ', StringSplitOptions.RemoveEmptyEntries);
Array.ForEach(words, Console.WriteLine);

В примере у нас есть несколько пробелов между словами. Это привело бы к пустые записи в результирующем массиве. Мы используем опцию опускать такие пустые Записи.StringSplitOptions.RemoveEmptyEntries

C# разделение строки на несколько символов

C# позволяет разбивать строку с помощью нескольких разделителей.

Program.cs
var text = "falcon;eagle,forest,sky;cloud,water,rock;wind";

var words = text.Split([',', ';']);
Array.ForEach(words, Console.WriteLine);

В примере мы разделили строку с помощью двух символов: запятая и точка с запятой.

var words = text.Split([',', ';']);

Перегруженный метод принимает массив символов в качестве параметр.String.Split

Ограничение количества подстрок

Мы можем ограничить количество подстрок с помощью перегруженного метода, который принимает метод Второй параметр.count

Program.cs
var text = "falcon,eagle,forest,sky,cloud,water,rock,wind";

var words = text.Split(',', 4);
Array.ForEach(words, Console.WriteLine);

В примере мы разбили строку на четыре подстроки.

$ dotnet run

eagle
forest
sky,cloud,water,rock,wind

Последняя строка содержит весь остальной текст.

C# разделение строка за строкой

Иногда мы можем захотеть разделить строки по другой строке, а не по символу. Для этого есть перегруженный метод.

Program.cs
var text = "hawkxxowlxxvulturexxeagle";

var birds = text.Split("xx");
Array.ForEach(birds, Console.WriteLine);

В примере мы разделили строку на строку "xx".

$ dotnet run
hawk
owl
vulture
eagle

C# разделение строки с помощью Regex.Split

Метод разбивает входную строку на массив подстроки в позициях, определенных регулярным выражением, совпадают. Учебник по регулярным выражениям в C# охватывает регулярные выражения выражения на языке C# более подробно.Regex.Split

Program.cs
using System.Text.RegularExpressions;

var text = "There are\t\t many clouds   in the \n sky.";

var rx = new Regex(@"\s+", RegexOptions.Compiled);
var data = rx.Split(text);

Array.ForEach(data, Console.WriteLine);

В примере предложение разбивается на слова по пробелам.

var rx = new Regex(@"\s+", RegexOptions.Compiled);

Регулярное выражение разбивает строку на один или несколько пробелов.

C# String.Join

В предыдущих примерах мы разбили строки на массив подстрок. Метод конкатенирует все элементы строки массива, используя указанный разделитель между каждым элементом.String.Join

Program.cs
List<string> words = ["falcon", "wood", "sky", "water"];

var text = string.Join(',', words);
Console.WriteLine(text);

В примере мы объединяем список слов с помощью символа-запятой.

$ dotnet run
falcon,wood,sky,water
