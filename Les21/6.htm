Пр 9. Задачи работы с файлами последовательного доступа.
    Назад
Задача 9.1 Дан строковый файл, содержащий по крайней мере один символ пробела. Удалить все его элементы, расположенные после первого символа пробела, включая и этот пробел.
Задача 9.2 Дан строковый файл,, содержащий по крайней мере один символ пробела. Удалить все его элементы, расположенные после последнего символа пробела, включая и этот пробел.
Задача 9.3 Дан строковый файл, содержащий по крайней мере один символ пробела. Удалить все его элементы, расположенные перед первым символом пробела, включая и этот пробел.
Задача 9.4 Дан строковый файл, содержащий по крайней мере один символ пробела. Удалить все его элементы, расположенные перед последним сим- волом пробела, включая и этот пробел.
Задача 9.5 Дан строковый файл. Упорядочить его элементы по возрастанию их кодов.
Задача 9.6 Дано целое число K (>0) и строковый файл. Создать два новых файла: строковый, содержащий первые K символов каждой строки исходного файла, и
символьный, содержащий K-й символ каждой строки (если длина строки меньше K, то в строковый файл записывается вся строка, а в символьный файл записывается пробел).
Задача 9.7 Дан строковый файл. Создать новый строковый файл, содержащий все строки исходного файла наименьшей длины (в том же порядке).
Задача 9.8 Дан строковый файл. Создать новый строковый файл, содержащий все строки исходного файла наибольшей длины (в обратном порядке).
Задача 9.9 Дан строковый файл. Создать новый строковый файл, в котором строки из исходного файла располагались бы в лексикографическом порядке, то есть по возрастанию кодов их символов, начиная с первого символа.
Задача 9.10 Дан строковый файл, содержащий даты в формате «день/месяц/год», причем под день и месяц отводится по две позиции, а под год — четыре (например, «16/04/2022»). Создать два файла целых чисел, первый из которых содержит значения дней, а второй — значения месяцев для дат из исходного строкового файла (в том же порядке).
Задача 9.11 Дан строковый файл, содержащий даты в формате, описанном в задании Задача 9.10. Создать два файла целых чисел, первый из которых содержит значения месяцев, а второй — значения лет для дат из исходного строкового файла (в обратном порядке).
Задача 9.12 Дан строковый файл, содержащий даты в формате, описанном в задании Задача 9.10. Создать новый строковый файл, содержащий все летние даты из исходного файла (в том же порядке). Если даты с требуемым временем года в файле отсутствуют, то оставить результирующий файл пустым.
Задача 9.13 Дан строковый файл, содержащий даты в формате, описанном в задании Задача 9.10. Создать новый строковый файл, содержащий все зимние даты из исходного файла (в обратном порядке). Если даты с требуемым временем года в файле отсутствуют, то оставить результирующий файл пустым.
Задача 9.14 Дан строковый файл, содержащий даты в формате, описанном в задании Задача 9.10. Найти строку, содержащую самую раннюю весеннюю дату. Если даты с требуемым временем года в файле отсутствуют, то вывести пустую строку.
Задача 9.15 Дан строковый файл, содержащий даты в формате, описанном в задании Задача 9.10. Найти строку, содержащую самую позднюю осеннюю дату. Двоичные файлы Если даты с требуемым временем года в файле отсутствуют, то вывести пустую строку.
Задача 9.16 Дан строковый файл, содержащий даты в формате, описанном в задании Задача 9.10. Создать новый строковый файл, в котором даты из исходного файла располагались бы в порядке убывания.
